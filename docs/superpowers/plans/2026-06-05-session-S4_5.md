# Session S4.5 — Human-Sounding Pronunciation Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (chosen for this session) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Several tasks are **human-in-the-loop checkpoints** (Adrian must LISTEN and approve) — they are clearly marked `🧑 ADRIAN CHECKPOINT` and must STOP for his ear; do not self-certify audio quality.

**Goal:** Replace the robotic browser Web-Speech pronunciation with pre-generated, human-sounding, correctly-pronounced ElevenLabs audio clips for all 17 by-the-glass wines, base64-embedded so the single shippable file still works offline by `file://` double-click.

**Architecture:** Offline, single-file-shippable, no backend, **no runtime TTS API calls**. Generate one short mp3 per wine ONCE (ElevenLabs `eleven_multilingual_v2` via the connected ElevenLabs MCP — no API key on disk), base64-embed each into a new generated `src/audio.js` as `window.BB.audio = { "<wine-id>": "data:audio/mpeg;base64,…" }`. A single helper `window.BB.playPronunciation(wineId, fallbackText, lang)` plays the clip via `new Audio(dataUri)` and falls back to the existing `speechSynthesis` path when a clip is missing or fails to load. Both speak entry points (the Pronunciation deck in `training.js` and a new 🔊 button on the Reference wine cards in `app.js`) route through that helper. The existing Python bundler already inlines `<script src>` files, so embedding keeps the app one-file shareable. The on-screen respelling stays the always-visible source of truth.

**Tech Stack:** ElevenLabs MCP (`mcp__elevenlabs__text_to_speech`, model `eleven_multilingual_v2`, free tier — confirmed authed, 10k chars/mo, 0 used); vanilla classic-script JS (`window.BB`); Python 3 stdlib (clip→`audio.js` assembler + tests); Node `--test` (helper + engine unit tests); the existing `build_single_file.py` bundler.

```python
# tools/build_audio_js.py — assemble src/audio.js from tools/audio_clips/<wine-id>.mp3
# Standard library only. Deterministic: clips ordered by data.js wines order.
# Regenerate: python tools/build_audio_js.py
import base64
import json
import subprocess
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]
DATA = ROOT / "src" / "data.js"
CLIPS = ROOT / "tools" / "audio_clips"
OUT = ROOT / "src" / "audio.js"

# The player helper. Self-contained: clip via new Audio(dataUri); on missing
# clip OR play() rejection OR media error, fall back to speechSynthesis.
HELPER = """window.BB.playPronunciation = function (wineId, fallbackText, lang) {
  var clip = window.BB.audio && window.BB.audio[wineId];
  function fallback() {
    if (typeof window.speechSynthesis === "undefined" ||
        typeof window.SpeechSynthesisUtterance === "undefined" || !fallbackText) return;
    var u = new window.SpeechSynthesisUtterance(fallbackText);
    if (lang) u.lang = lang;
    window.speechSynthesis.cancel();
    window.speechSynthesis.speak(u);
  }
  if (!clip) { fallback(); return; }
  try {
    if (window.speechSynthesis && window.speechSynthesis.cancel) window.speechSynthesis.cancel();
    var a = new Audio(clip);
    var done = false;
    a.addEventListener("error", function () { if (!done) { done = true; fallback(); } });
    var p = a.play();
    if (p && typeof p.catch === "function") p.catch(function () { if (!done) { done = true; fallback(); } });
  } catch (e) { fallback(); }
};
"""


def wine_ids_in_order():
    snippet = (
        "global.window={};const fs=require('fs');"
        f"eval(fs.readFileSync({json.dumps(str(DATA))},'utf8'));"
        "process.stdout.write(JSON.stringify(global.window.BB.data.wines.map(function(w){return w.id;})));"
    )
    res = subprocess.run(["node", "-e", snippet], capture_output=True, text=True)
    if res.returncode != 0:
        raise RuntimeError("node failed to read wine ids:\n" + res.stderr)
    return json.loads(res.stdout)


def main():
    ids = wine_ids_in_order()
    audio_lines, fallback = [], []
    for wid in ids:
        mp3 = CLIPS / (wid + ".mp3")
        if mp3.exists():
            b64 = base64.b64encode(mp3.read_bytes()).decode("ascii")
            audio_lines.append('  "%s": "data:audio/mpeg;base64,%s"' % (wid, b64))
        else:
            fallback.append(wid)
    out = (
        "// GENERATED by tools/build_audio_js.py — DO NOT EDIT BY HAND.\n"
        "// One base64 mp3 per wine id (ElevenLabs eleven_multilingual_v2). The app plays\n"
        "// the clip and falls back to Web Speech for any id in window.BB.audioFallback\n"
        "// or any clip that fails to load. Regenerate: python tools/build_audio_js.py\n"
        "window.BB = window.BB || {};\n"
        "window.BB.audio = {\n" + ",\n".join(audio_lines) + ("\n" if audio_lines else "") + "};\n"
        "window.BB.audioFallback = " + json.dumps(fallback) + ";\n"
        + HELPER
    )
    OUT.write_text(out, encoding="utf-8")
    print("Wrote %s — %d clip(s), %d fallback id(s)." % (OUT, len(audio_lines), len(fallback)))


if __name__ == "__main__":
    main()
```

```js
        const wine = (window.BB.data.wines || []).find(w => w.id === id);

          ? window.BB.training.langFor(wine.country) : "";
        const say = wine.pronunciation ? wine.pronunciation.say : wine.name;
        window.BB.playPronunciation(id, say, lang);
      });
```
