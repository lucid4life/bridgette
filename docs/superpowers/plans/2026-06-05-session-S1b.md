## Locked decisions (resolve ambiguity before coding)

1. **`pronunciation.respell` = phonetic respelling of the full wine NAME as Adrian would say it to a guest** (matches the contract example `{ say: "Hiedler Löss", respell: "HEED-ler LURSS" }`). The respelling is the source of truth. Each hard token (grape/region/producer) is verified against an authoritative wine-pronunciation source via web search; citations are recorded in `docs/research/2026-06-05-pronunciation-structure-sources.md`.
2. **Structure scale is strict `low | medium | high`** for `acidity`, `body`, `tannin`; **`sweetness` ∈ `dry | off-dry | medium-dry | medium-sweet | sweet`** (BTG list is all dry/off-dry). NEVER 1–5. Seed from grape/region norms (textbook, citable). Any value that cannot be confirmed (e.g. a specific Riesling's residual sugar) stays conservative AND is flagged via a new optional **`structureNote`** string ("Sweetness not confirmed — taste to verify"). This keeps the four `structure` values inside the allowed set while never asserting an unverified sensory fact.
3. **`category` is cleaned** to `Bubbly | White | Rosé | Red | No-Alcohol` and a boolean **`glass: true`** is added to every wine (all 17 are by-the-glass). Safe because no filter chip keys off the old `"BTG"` suffix (`data-filter` chips match `group`/`tags`, never the category string's "btg").
4. **Scope = the 17 wines already in `data.wines`.** Bottle-only wines stay as reference strings inside `bottleLadders`/`bottleMap`/`translator.bottleOptions` (they are not drilled in v1). "Every wine" = every entry in `data.wines`.
5. **Food shape:** add/sharpen `why` (structural WSET-lever reason), convert `flags` from delimited string → **array** (future Safety deck + accuracy), add optional `mnemonic`. **Keep `wine`/`cocktail`/`zero` as single strings** (single best pick — `app.js` rendering, the pairing builder, and the S4 Pairing deck all consume them as the one best answer). No redundant `food.pair` array is invented.
6. **`translator.bestGlass` is stored as the FULL corrected wine name** (e.g. `"Bodega Cerrón Remordimiento Blanco"`, not the table's shorthand `"Bodega Cerron Blanco"`) so it references a real entry in `data.wines` and the S4 Translator deck can link to the wine. Test-enforced.
7. **`translator` columns map:** `ask` ← "Guest asks for"; `bestGlass` ← "Best Bridgette answer" (primary glass, full name); `bottleOptions` ← "Second or bottle option" (array of names); `familiar` ← "What feels familiar"; `different` ← the explanation half of the last column; `phrase` ← the quoted "Say:/Be honest:/Ask:" sentence in the last column. `aliases` ← lowercase guest synonyms/abbreviations.
8. **Preserve test-load-bearing phrases** verbatim in the translator data so the bundled output still contains them: `"If you like Sauvignon for crispness"` (Sauvignon Blanc row `phrase`) and `"If you like Malbec"` (Malbec row `phrase`). The heading "Common guest ask translator" stays in `index.html`.
9. **`lessons[]` are stubs only** (id + title), matching spec §10's seven lessons, as `learnLink` anchor targets for S3/S4. No bodies/quick-checks yet.

```javascript
    function joinList(value) {
      return Array.isArray(value) ? value.join(", ") : (value == null ? "" : String(value));
    }

    function structureText(structure) {
      if (!structure || typeof structure !== "object") return joinList(structure);
      const parts = [];
      if (structure.acidity)  parts.push(`${structure.acidity} acidity`);
      if (structure.body)     parts.push(`${structure.body} body`);
      if (structure.tannin)   parts.push(`${structure.tannin} tannin`);
      if (structure.sweetness) parts.push(structure.sweetness);
      return parts.join(", ");
    }

    function structureMeters(structure, note) {
      if (!structure || typeof structure !== "object") return "";
      const levels = {low: 1, medium: 2, high: 3};
      const row = (label, value) => {
        const n = levels[value] || 0;
        const segs = [1,2,3].map(i =>
          `<span class="smeter-seg${i <= n ? " on" : ""}" aria-hidden="true"></span>`).join("");
        return `<div class="smeter" role="img" aria-label="${escapeHtml(label)}: ${escapeHtml(value || "n/a")}">
          <span class="smeter-label">${escapeHtml(label)}</span>
          <span class="smeter-track">${segs}</span>
          <span class="smeter-value">${escapeHtml(value || "")}</span></div>`;
      };
      const sweet = structure.sweetness
        ? `<div class="smeter sweet"><span class="smeter-label">Sweetness</span>
             <span class="smeter-value chip">${escapeHtml(structure.sweetness)}</span></div>` : "";
      const noteHtml = note ? `<p class="smeter-note">≈ ${escapeHtml(note)}</p>` : "";
      return `<div class="structure-meters" aria-label="Structure (low to high)">
        ${row("Acidity", structure.acidity)}${row("Body", structure.body)}${row("Tannin", structure.tannin)}${sweet}
      </div>${noteHtml}`;
    }
```
