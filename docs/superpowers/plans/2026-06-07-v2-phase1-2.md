# Bridgette Training v2 — Phase 1 + 2 (Foundation) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lock the human-approved v2 foundation — accuracy-fixed + enriched content in `src/data.js`, and a non-UI SvelteKit+PWA scaffold in `app/` with the v1 engine ported to ESM (all tests green), TS interfaces, frozen card-ID snapshot + golden progress fixture, design tokens, and the 17 MP3s as static assets — WITHOUT building any screens (Phase 3).

**Architecture:** "Port the brain, rebuild the shell." Phase 1 enriches the single canonical content file (`src/data.js`) with the §12 accuracy fixes + v2 fields, web-verified, keeping the v1 suite green. Phase 2 scaffolds SvelteKit (`adapter-static`, SPA), extracts the mockup's tokens to `app/src/app.css` as the visual contract, ports the pure halves of `training.js`/`wineschool.js` to `app/src/lib/engine/*` as ESM (preserving card-`id` slugs + the `bb_progress_v1` key byte-for-byte), converts the ~50 Node tests to Vitest, authors TS interfaces, generates the typed data module from `src/data.js`, freezes a card-ID snapshot + golden `bb_progress_v1` fixture + migration test, and ships the 17 MP3s static with a fallback-chain util.

**Tech Stack:** SvelteKit 2 + Svelte 5 (runes), Vite, `@sveltejs/adapter-static`, `@vite-pwa/sveltekit` (`registerType:'prompt'`), Vitest, `@playwright/test`, TypeScript. Phase 1 stays vanilla JS in `src/data.js` (v1 classic-script contract) + Python/Node v1 checks.

**Unattended note:** Run fully unattended. Never wait for input. If a sommelier/content fact cannot be confidently web-verified, do NOT assert it — append it to `docs/v2-open-questions.md` and move on with the safest reversible default. Commit frequently. Never touch `main`.

```javascript
// app/src/lib/engine/wineschool.js — ported pure deductive logic (ESM).
// Source: src/wineschool.js (DOM rendering half intentionally NOT ported).
export const DG_DIMS = ['category', 'acidity', 'body', 'tannin', 'sweetness'];

export function wineValue(wine, dim) {
  if (dim === 'category') return wine.category;
  return wine.structure ? wine.structure[dim] : undefined;
}

export function deduce(wines, clues) {
  clues = clues || {};
  const active = DG_DIMS.filter((d) => clues[d]);
  if (!active.length) return [];
  const rows = [];
  (wines || []).forEach((w) => {
    let matched = 0;
    active.forEach((d) => {
      const wv = wineValue(w, d);
      if (wv != null && String(wv).toLowerCase() === String(clues[d]).toLowerCase()) matched++;
    });
    if (matched > 0) rows.push({ wine: w, matched, total: active.length, exact: matched === active.length });
  });
  rows.sort((a, b) => b.matched - a.matched);
  return rows;
}

export function checkQuickCheck(lesson, choiceIndex) {
  return !!lesson && !!lesson.quickCheck && choiceIndex === lesson.quickCheck.answer;
}
```

```typescript
// app/src/lib/audio/playPronunciation.ts — MP3 → Web-Speech → (respelling shown by UI).
// Ported from src/audio.js; clip source is now a static asset, not base64.
let currentAudio: HTMLAudioElement | null = null;

export function audioUrl(wineId: string): string {
  return `/audio/${wineId}.mp3`;
}

/** Play the pronunciation clip for a wine; fall back to Web Speech with `lang`.
 *  The on-screen respelling remains the visible source of truth regardless. */
export function playPronunciation(wineId: string, fallbackText: string, lang?: string): void {
  const speak = () => {
    if (typeof window === 'undefined') return;
    if (typeof window.speechSynthesis === 'undefined' ||
        typeof window.SpeechSynthesisUtterance === 'undefined' || !fallbackText) return;
    const u = new window.SpeechSynthesisUtterance(fallbackText);
    if (lang) u.lang = lang;
    window.speechSynthesis.cancel();
    window.speechSynthesis.speak(u);
  };
  if (typeof window === 'undefined') return;
  if (window.speechSynthesis?.cancel) window.speechSynthesis.cancel();
  if (currentAudio) { try { currentAudio.pause(); } catch { /* noop */ } currentAudio = null; }
  if (!wineId) { speak(); return; }
  try {
    const a = new Audio(audioUrl(wineId));
    currentAudio = a;
    let settled = false;
    a.addEventListener('error', () => { if (!settled) { settled = true; speak(); } });
    const p = a.play();
    if (p && typeof p.then === 'function') {
      p.then(() => { settled = true; }, () => { if (!settled) { settled = true; speak(); } });
    }
  } catch { speak(); }
}
```
