# Bridgette Training v2 — Synthesis Audit

**Date:** 2026-06-07 · **Branch:** `v2-app` · **Scope:** the six core areas (wine knowledge, food-wine, food-cocktail, pronunciation, recommendations/translator, glass→bottle upselling), plus learning-science, UX, a11y, perf/offline.

## 1. Executive summary

Phase 3 shipped a solid, accurate, accessible core loop on the right foundation (Leitner + confidence + a calm, dual-coded reasoning layer). The audit's central finding is **a structural mismatch between what the product is *for* and what it currently *teaches as retrieval*.** Five themes dominate:

1. **The data is far richer than the UI exposes, and far thinner than the locked scope demands.** Every glass wine already carries `upgrade`, decoded price, `profile`, and `objections[]`; every translator row carries `bottleOptions` and a point-of-difference (`different`); every food carries `cocktail`/`zero`/`why` — yet Reference renders almost none of it. Simultaneously, the ~33 non-glass bottles, all beer, the entire dessert/sherry/port/amaro program, and matinee are names-only or absent. The product cannot teach two of its six reasons-to-exist (upselling, the bottle half of the translator) because the records don't exist.
2. **Three core areas have ZERO retrieval practice.** Food-cocktail pairing (area 3), glass→bottle upselling (area 6), and the *reasoning/why* itself are recognition-only or display-only. The learner rehearses the answer token, never the floor move or the structural "why" — even box-5 scenario grades only the wine name and suppresses the why.
3. **The substitution translator — the stated #1 floor skill — is the most under-built surface relative to its priority.** Both the Reference card and the practice deck drop `bottleOptions` and `different`, there is no cue search/alias matching, and ~10 high-frequency guest asks (Gamay, Viognier, Albariño, Barolo, Cava, "sweet plush red") have no row despite honest cellar matches existing.
4. **The Guest Simulator — the v2 differentiator — runs at one difficulty, scores two of three spec beats, never writes back to Leitner, and never rehearses the upsell.** It currently degrades to a second flashcard surface.
5. **Honest-readiness has two leaks and distractors are too easy.** Readiness % is not confidence-weighted, it folds self-graded pronunciation into an "objective" score, and the highest-value MC decks use random full-list foils instead of structurally-adjacent confusables — all of which inflate the headline shift-ready number.

**Single highest-leverage move toward "best server on the floor":** *Build the recommendations/upselling spine end-to-end* — promote the ~15 translator-referenced bottles to real records (COMP-01), expose `bottleOptions`/`different`/decoded-price/`objections` on the Translator + Wine reference cards (UX-11/CT-04/UX-02), and add the two missing retrieval decks (cocktail-pairing LS-01, upsell LS-02) plus the simulator's bottle-upgrade beat. This single thread directly serves areas 3, 5, and 6 — the floor moves that separate a good server from the best one — and most of the UI half is already data that exists and merely needs rendering.

## 2. Methodology

Six independent adversarial angles were run, then adjudicated by a reviewer who re-verified every claim against the current source (the `verifiedSeverity` is authoritative), recorded rejections, and added reviewer-found findings:

- **UX / interaction / IA** — kept 19, rejected 1 (UX-06), added 2.
- **Accessibility (WCAG 2.2)** — kept 13, rejected 4 (A11Y-06/13/14/16), added 2.
- **Content accuracy + completeness** — kept 17, rejected 0, added 2.
- **Learning-science efficacy** — kept 6, rejected 0, added 1.
- **Performance / CWV / bundle / offline** — kept 10, rejected 0, added 3.
- **Competitive teardown** — kept 13, rejected 1 (CT-03), added 2.

**Counts (kept findings carried into this backlog): 70 total.**

By severity: **P0 critical 0 · P1 high 16 · P2 medium 30 · P3 low 24.** (No safety-critical / flat-wrong-fact items survived adjudication — notably ACC-02, a proposed "fix" that would have *introduced* an error, was caught and downgraded.)

By angle (kept + added): UX 21 · a11y 15 · content 19 · learning-science 7 · perf 13 · competitive 15. Several findings overlap across angles and are merged in the backlog below (see merge notes).

## 4. Detail by theme

### (a) Recommendations & the substitution translator (core area 5 — the #1 floor skill)

**CT-04 (+UX-11) — P1, S→M, recommendations.** *Location:* `reference/+page.svelte:112-121`; `src/data.js` translator[] lines 27-47. *Evidence:* the Translator card renders only `t.ask → t.bestGlass + t.phrase`. Every row also carries `bottleOptions[]` (e.g. Cabernet → `['White Rock Cabernet Sauvignon','Chateau Larose Perganson','Aia Vecchia Sor Ugo']`), `aliases`, `familiar`, and `different` (e.g. "Claret is Cabernet blended with Merlot, so it is a little softer than a big Napa Cab") — all dropped. There is no search/alias matching on the Translator filter (only the Wine filter has search at lines 47-51), so "something like Meiomi" can't resolve. *Impact:* the lookup screen for the #1 floor skill reduces the pour+upgrade+point-of-difference+objection move to a single phrase. *Fix:* render `bottleOptions` as the upgrade line (this is the canonical bottle source for translator rows — NOT the wine's `upgrade` field; verify which is canonical per row), render `different` as the point-of-difference, add an objections accordion from the matched wine, and add multi-entry + alias search. Note the practice deck `genTranslator` (`training.js:147-164`) has the SAME omission — it only drills ask→bestGlass+phrase — worth a fast-follow so the drilled skill matches the floor task. *Effort:* S for rendering, M with search.

**COMP-04 — P1, L, recommendations.** *Location:* `src/data.js:27-48`; `source_menus/calgary-drink.txt` (Domaine de Colette 41-42, Clos Bellane 110-111, Raventós 7). *Evidence:* 19 translator rows but no row for Gamay/Beaujolais, Viognier/white-Rhône, Gewürztraminer/aromatic, Albariño, Barolo/Barbaresco-by-name, Cava, or "sweet/plush red (Meiomi/Apothic/19 Crimes)" — while honest cellar matches exist (Domaine de Colette IS Gamay; Clos Bellane IS Marsanne/Viognier/Roussanne; Neverwine IS Albariño; Raventós is on the menu). *Impact:* the locked note says "the list is niche/obscure so the translator is everything"; these gaps are direct holes in area 5. *Fix:* add rows (each with `ask, aliases, bestGlass, bottleOptions, familiar, different, phrase`); the "sweet plush red" row honestly states we don't sweeten reds → Claret/Cerrón Tinto as the closest dry option. Grüner-by-name is already covered (Hiedler) — skip it.

**LS-05 — P1, M, recommendations.** *Location:* `training.js:131-140` (pickDistractors rotates the whole 17-name pool), `:157` (translator), `:227` (pairing), `:178/:190` (wine-identity); `simulator/+page.svelte:43` (random `pick(wineNames,3)`). *Evidence:* mystery (`adjacentWines` :308-326) and structure (LOW cohort :241-243) are adjacency/cohort-aware, but the highest-value recall decks use seed-rotated full-list foils, so a steak pairing can offer a sparkling/Txakoli/Riesling. *Impact:* random foils let the learner solve by elimination, inflating promotion AND the readiness score across three core areas. *Fix:* reuse `adjacentWines` to pick nearest-structure foils relative to the ANSWER wine for translator/pairing/wine-identity and the simulator pick. *Effort:* M.

**LS-03 — P1, M, recommendations.** *Location:* `training.js:641-647` (modeForBox), `:652-656` (whyDisplay), `+page.svelte:77-80`. *Evidence:* mc/typed/scenario all grade the NAME only; at box≥5 the scenario prompt asks for a reason but `submitTyped` still matches the name and `whyDisplay` returns EMPTY at box≥5 — the why is neither elicited nor shown at the top box. *Impact:* the generation effect is unused for the reasoning the product exists to teach (areas 1/2/3/5/6). *Fix:* at box≥4, add a self-generation beat — prompt the learner to say/type the why before reveal, then reveal `card.why` and self-rate ("Did you say the reason?" Sure/Shaky), keeping name-grading as the objective gate (mirror `recordWithConfidence`). Aligns with spec §7 "one reason not three." *Effort:* M.

**A11Y-07 — P2, M, recommendations** (re-coded a11y→recommendations). *Location:* `progress/+page.svelte:105-107`; `+page.svelte` onMount :13-18. *Evidence:* all weak-pills link to the SAME `/?start=smart` generic mixed session — there is no `&card=` handling — and the visible text is the answer side (prompt only in `aria-label`). **ACC-04 — P3, S, recommendations.** *Location:* `src/data.js:23`; `training.js:66`. *Evidence:* Bodega Cerrón Tinto `aliases` include syrah/shiraz/malbec (NOT grape synonyms) but `aliases` is consumed ONLY by `gradeTyped` (answer-matching), never rendered as "also known as" — so it's currently harmless. *Fix:* add an authoring comment that `aliases` = guest-ask/answer-matching only and must never be surfaced as a synonym.
